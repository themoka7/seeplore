## 무엇인가요?

seeplore는 **"왜 그럴까?"를 눈으로 따라가는 교육용 웹 다큐멘터리 시리즈**입니다. 지금까지 <!-- n -->35<!-- /n -->편을 냈고, 그중 <!-- nEn -->21<!-- /nEn -->편은 영어판도 있습니다.

- **축 하나를 따라갑니다.** 작품마다 시간·거리·깊이 같은 축이 하나 있습니다. 한국사는 연도, 바다는 수심, 블랙홀은 시계가 느려지는 정도. 축을 따라가면 이야기가 됩니다.
- **보는 것과 듣는 것을 함께.** 장면을 직접 넘겨 볼 수도 있고, '다큐멘터리 모드'를 켜면 음성 해설에 맞춰 화면이 저절로 움직입니다.
- **숫자는 계산하거나 출처에서 가져옵니다.** 비행기 날개 둘레의 공기, 실제로 학습시킨 작은 AI, 드론 450대의 비행처럼 화면의 값은 가능한 한 직접 계산합니다. 통계는 공식 자료의 기준일과 함께 적습니다.
- **중학생이 혼자 보고 이해할 수 있게.** 어려운 용어는 쉬운 말로 풀고, 누구나 겪는 일에 빗대어 설명합니다. 수업 화면 자료로도, 어른의 "그게 원래 어떻게 되는 거였지?"에도 씁니다.

## 어떻게 만드나요?

아빠와 아들이 주제를 고르고 검토하고, 나머지는 AI와 자동화 도구가 맡습니다. 누가 무슨 일을 하는지는 [가상의 사무실](https://seeplore.com/team)에서 볼 수 있습니다.

- 작품마다 저장소 하나, 주소 하나(`<작품>.seeplore.com`). three.js · GSAP · Vite · TypeScript, 지도 작품은 OpenLayers.
- 음성 해설은 음성 합성으로 만들고, 화면은 그 음성의 시각에 맞춰 움직입니다.
- 블로그 글과 쇼츠는 매주 자동으로 만들어 올립니다.

## 이 저장소

seeplore.com 허브입니다. 의존성 없이 `node` 만으로 빌드합니다.

| 것 | 하는 일 |
|---|---|
| `series.json` | 시리즈 목록의 원본 — 모든 작품 사이트가 이 파일을 읽어 시리즈 줄을 그립니다 |
| `scripts/build.mjs` | 첫 페이지 · 소개(`/about`) · `llms.txt` · sitemap 을 만듭니다 (영어판은 `scripts/en.mjs`) |
| `scripts/team.mjs` + `public/team/` | [가상의 사무실](https://seeplore.com/team) — 캔버스로 그린 인터랙티브 픽셀 사무실 |

```bash
node scripts/build.mjs   # → dist/
```

개발 메모는 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
